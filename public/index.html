使用说明

配置 Jenkins 使用镜像

# 方法一：修改 Jenkins 配置文件
# Linux/Mac
sudo vim /var/lib/jenkins/hudson.model.UpdateCenter.xml

# Windows (Jenkins 安装目录)
C:\Program Files\Jenkins\hudson.model.UpdateCenter.xml

# 将 url 修改为：
http://jenkins-plugins.foresai.com/update-center.json

通过系统管理配置

  1. 登录 Jenkins 管理界面
  2. 进入 "系统管理" → "插件管理" → "高级"
  3. 将 "升级站点" URL 修改为：
    http://jenkins-plugins.foresai.com/update-center.json
  4. 点击 "提交" 保存

Windows 配置说明

  1. 打开 Jenkins 安装目录（默认：C:\Program Files\Jenkins）
  2. 找到并打开 `hudson.model.UpdateCenter.xml` 文件
  3. 将文件中的 `url` 属性修改为：
    http://jenkins-plugins.foresai.com/update-center.json
  4. 保存文件，重启 Jenkins 服务
  5. 在 Jenkins 管理界面中，进入 "系统管理" → "插件管理" → "高级"，确认 URL 已更新
